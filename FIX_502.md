# Fix Telegram 502 Bad Gateway

Error `502 Bad Gateway` comes from **Telegram servers** (temporary), not from bot logic.

## What we changed in `kaijaklike_bot.py`

1. `_GlobalExceptionHandler` treats 502/503/504/timeout/connection errors as **transient**
2. Does **not** send spam `Bot Error (internal)` for these
3. Logs warning + notifies admin at most once per 15 minutes
4. Polling retries 502 after 15s automatically

## Deploy

Render will auto-deploy after `kaijaklike_bot.py` is updated on main.

If 502 continues for hours: check https://status.telegram.org and Render outbound network.
